# Manas College — Professional Resume Studio

A browser-based resume builder branded for **Manas College of Science Technology & Management**. The college logo is embedded in `index.html`, so the application can run offline without needing an internet connection or a separate image file.

## Run the software
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Enter your details and paste the target job description.
4. Choose one of the 24 resume designs.
5. Use **Print / Save PDF** to save a PDF, or **Download HTML** to export a standalone resume.

No installation, server, API key, or account is required.

## Features
- Manas College branding and supplied college logo.
- 24 selectable resume design styles with different layout structures.
- Live resume preview and optional profile photo.
- Job-description keyword overlap estimate, matched/missing keyword indicators.
- Work experience, education, skills, projects, certifications, languages, and leadership/volunteer sections.
- Browser-local draft auto-save.
- Export profile backup as JSON and restore it later.
- Sample profile to preview the software quickly.
- Copy resume text, standalone HTML export, and print/save as PDF.
- Responsive layout for desktop and mobile screens.

## Important ATS and privacy notes
- The ATS percentage is a **keyword-overlap estimate**, not a real test against an employer's ATS software and not a guarantee of selection.
- The app does not call an AI model or send your information to a server. Tailoring depends on the facts and wording you enter. Never add skills, dates, qualifications, or achievements that are not true.
- Your draft is saved in the browser's local storage on the device you use. Use **Export profile backup** before clearing browser data or moving to another device.
- A profile photo is optional. For many ATS-focused applications, a text-first resume without a photo is the safer default unless the employer or local norms request one.
